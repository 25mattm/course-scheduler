# Course Scheduler — Backend

A REST API for managing courses, students, and course enrollments, built with Spring Boot and backed by MySQL. Students can enroll in many courses and courses can have many students — a many-to-many relationship managed through JPA.

This is the backend half of a full-stack project. The React frontend lives in a separate repository: [course-scheduler-frontend](https://github.com/25mattm/course-scheduler-frontend).

## Tech stack

- **Java 21**
- **Spring Boot** (Spring Web, Spring Data JPA)
- **Hibernate** as the JPA implementation
- **MySQL** for persistence
- **Maven** for build and dependency management

## Data model

Three tables, two entities plus a join table:

- `courses` — id, code, name, instructor
- `students` — id, name, email
- `enrollments` — a join table linking students to courses (many-to-many), with foreign keys to both

The `enrollments` table is generated by Hibernate from the `@ManyToMany` mapping on the `Student` entity.

## API endpoints

### Courses
- `GET /courses` — list all courses
- `GET /courses/{id}` — get one course
- `POST /courses` — create a course
- `PUT /courses/{id}` — update a course
- `DELETE /courses/{id}` — delete a course
- `GET /courses/{id}/students` — list students enrolled in a course (roster)

### Students
- `GET /students` — list all students
- `GET /students/{id}` — get one student
- `POST /students` — create a student
- `DELETE /students/{id}` — delete a student
- `POST /students/{studentId}/enroll/{courseId}` — enroll a student in a course
- `DELETE /students/{studentId}/enroll/{courseId}` — unenroll a student from a course

## Running locally

**Prerequisites:** Java 21, MySQL running locally on port 3306, and a database named `course_scheduler`.

**1. Create the database:**

```sql
CREATE DATABASE course_scheduler;
```

**2. Set your database credentials as environment variables.** The app reads them from `application.properties`, which contains no hardcoded passwords:

```bash
export DB_USERNAME=your_mysql_username
export DB_PASSWORD=your_mysql_password
```

**3. Run the application:**

```bash
./mvnw spring-boot:run
```

The API starts on `http://localhost:8080`. Hibernate creates the tables automatically on first run.

## Notes

Database credentials are kept out of source control via environment variables, and `.gitignore` excludes local config and IDE files.
